# Public-API coverage (plans/M_01.txt T6)

Generated by `scripts/coverage_matrix.py` (`make coverage`); do not edit by hand. The script is the
gate: it exits 1 when an operation lacks a kind, an annotation is invalid, or a facade def is in no row.

Every released operation (every public def of `frame.bend`) has a row; a row has the six kinds:
**success**, **null** (input with nulls), **empty** (zero rows; **0col** marks a zero-column frame case),
**invalid** (an error path), **eager** and **lazy** (the lazy twin, with `collect_raw` / `collect` /
`collect_full` agreeing with the eager dump, `tests/regress/lib/rx.bend` `four`). A cell is a test file
holding such a case (`#@ cover` annotation, checked: the file must call the operation) or `n/a [k]` with
the reason k listed below (`#@ na`, reason required). `other test files` counts the tests that call the
operation without an annotation (a heuristic, report only). Cases are DF.dump-based with the expectation
reasoned first and confirmed against Polars 2.0.0 where the semantics match (`bench/coverage/`), the
documented departures (DESIGN.md 14, 15) applied by hand.

14 annotated test files, 99 annotation lines.

What the gate proves and what it does not. It proves that every row has every kind accounted for by a
case named in an annotation, that each annotation names an operation its file really calls, and that no
facade def is outside the matrix. It cannot prove that a named case is a good one: whether the case in the
file really holds nulls / zero rows / a refusal is the author's assertion, checked by review. The cases
themselves are real tests (`make test` runs them and compares every dump with its expectation).

### n/a reasons

1. a dtype builder has no input to be empty (the cast over a zero-row frame is covered)
2. a dtype builder cannot be given bad input (a refused cast target is the cast's case)
3. a checked integer has no null form (an SNull scalar is s_null, covered in expr_cond.bend)
4. a scalar builder takes one value: there is no zero-row form
5. a builder, not a plan node: the scalar it builds is used by the lazy is_in below
6. the argument is an already valid Frame / Column / name: no input can be refused (a repeated name is from_columns' error, covered)
7. an eager frame function: the lazy API starts from DF.source and never builds, inspects or prints a frame (collect_show and collect_schema are covered in api_plans.bend)
8. head takes any U32 and clamps to the height: no input can be refused (DESIGN 15.2.3)
9. an offset or length beyond the height is clamped, never an error (DESIGN 15.2.3)
10. tail takes any U32 and clamps to the height: no input can be refused (DESIGN 15.2.3)
11. an environment / plan tree holds no cell values: nulls are in the frames the cases bind (covered by the collect cases)
12. building an environment or a Source plan cannot fail (a bad plan or binding is reported by collect_schema / validate_bindings / collect, covered)
13. the answer is a dtype list / a text: a null cell changes none of them
14. the argument is an error value / a name: nothing zero-row to give
15. a read's lazy twin is scan_csv + collect_engine (the collect_engine row), compared here with the eager reads
16. collecting a plan is the lazy API itself; its eager twins are the reads above
17. scan_csv always uses the default (Auto) storage: the readers' choice is eager-only, the Auto reads are compared with the scans
18. both take a valid Frame (and a Bool) and cannot fail
19. eager frame functions: the scan / collect path picks its storage itself

## Def-call coverage over src/

Method: a static call graph (see the header of `scripts/coverage_matrix.py`). A def *mentions* another def
when its body names it (qualified through the file's import aliases, or bare inside its own module).
Entry points are the 368 defs that a test (or a `tests/**/lib` helper a test imports) calls directly,
`frame.bend` defs and `src/` defs alike. A def is *reached* when a path of mentions leads to it. Two
reach columns: **via facade** follows only the entries that are `frame.bend` defs (what the public API
alone can reach); **reached** adds the `src/` defs the tests call directly (the proof-style and unit tests).
This over-approximates what runs (a branch no test takes still counts, an error path is reached when its
function is) and misses a def used only as a value without its name in a body: read it as "no test can
reach these", not as line coverage. Reported, not gated.
